ಪರಿವಿಡಿ

  1. ಮೊದಲನೆಯ ಅಧ್ಯಾಯ - ಮಂಗಳಾಚರಣೆ
  2. ಎರಡನೆಯ ಅಧ್ಯಾಯ - ಸಿದ್ಧಮುನಿ ಹಾಗೂ ನಾಮಧಾರಕನ ಭೇಟಿ
  3. ಮೂರನೆಯ ಅಧ್ಯಾಯ - ದೂರ್ವಾಸರ ಶಾಪ
  4. ನಾಲ್ಕನೆಯ ಅಧ್ಯಾಯ - ಅನಸೂಯೆಯ ಮಹಿಮೆ
  5. ಐದನೆಯ ಅಧ್ಯಾಯ - ಶ್ರೀಪಾದವಲ್ಲಭರ ಅವತಾರ
  6. ಆರನೆಯ ಅಧ್ಯಾಯ - ಗೋಕರ್ಣದಲ್ಲಿ ಆತ್ಮಲಿಂಗಪ್ರತಿಷ್ಠಾಪನೆ
  7. ಏಳನೆಯ ಅಧ್ಯಾಯ - ಗೋಕರ್ಣಕ್ಷೇತ್ರ ಮಹಿಮೆ
  8. ಎಂಟನೆಯ ಅಧ್ಯಾಯ - ಶನಿಪ್ರದೋಷದ ಮಹಾತ್ಮೆ
  9. ಒಂಭತ್ತನೆಯ ಅಧ್ಯಾಯ - ಅಗಸನು ರಾಜನಾದ ವೃತ್ತಾಂತ
  10. ಹತ್ತನೆಯ ಅಧ್ಯಾಯ - ವಲ್ಲಭೇಶನ ಪ್ರಸಂಗ
  11. ಹನ್ನೊಂದನೆಯ ಅಧ್ಯಾಯ - ನೃಸಿಂಹಸರಸ್ವತಿಗಳ ಅವತಾರ
  12. ಹನ್ನೆರಡನೆಯ ಅಧ್ಯಾಯ - ಶ್ರೀ ಗುರುಗಳ ಸಂನ್ಯಾಸ ಸ್ವೀಕಾರ
  13. ಹದಿಮೂರನೆಯ ಅಧ್ಯಾಯ - ಸಾಯಂದೇವನ ಭೇಟಿ
  14. ಹದಿನಾಲ್ಕನೆಯ ಅಧ್ಯಾಯ - ದುಷ್ಟಯವನನ ಶಾಸನ
  15. ಹದಿನೈದನೆಯ ಅಧ್ಯಾಯ - ತೀರ್ಥಯಾತ್ರೆಗಳ ನಿರೂಪಣೆ
  16. ಹದಿನಾರನೆಯ ಅಧ್ಯಾಯ - ದೌಮ್ಯರ ಮೂರು ಜನ ಶಿಷ್ಯರ ಗುರುಭಕ್ತಿ
  17. ಹದಿನೇಳನೆಯ ಅಧ್ಯಾಯ - ಮೂರ್ಖಬಾಲಕನ ಉದ್ಧಾರ
  18. ಹದಿನೆಂಟನೆಯ ಅಧ್ಯಾಯ - ಅವರೇಬಳ್ಳಿಯನ್ನು ಬುಡಸಮೇತ ಕಿತ್ತುಹಾಕಿದುದು
  19. ಹತ್ತೊಂಭತ್ತನೆಯ ಅಧ್ಯಾಯ - ಯೋಗಿನಿಯರ ಗುರುಭಕ್ತಿ
  20. ಇಪ್ಪತ್ತನೆಯ ಅಧ್ಯಾಯ - ಗುರುಪಾದುಕಾ ಪೂಜೆಯ ಮಹಿಮೆ
  21. ಇಪ್ಪತ್ತೊಂದನೆಯ ಅಧ್ಯಾಯ - ಬಾಲಸಂಜೀವನ
  22. ಇಪ್ಪತ್ತೆರಡನೆಯ ಅಧ್ಯಾಯ - ಬರಡೆಮ್ಮೆಯಿಂದ ಹಾಲು ಕರೆದದ್ದು
  23. ಇಪ್ಪತ್ಮೂರನೆಯ ಅಧ್ಯಾಯ - ಬ್ರಹ್ಮರಾಕ್ಷಸನು ಮುಕ್ತನಾದದ್ದು
  24. ಇಪ್ಪತ್ನಾಲ್ಕನೆಯ ಅಧ್ಯಾಯ - ತ್ರಿವಿಕ್ರಮ ಯತಿಗೆ ವಿಶ್ವರೂಪದರ್ಶನ ಮಾಡಿಸಿದುದು
  25. ಇಪ್ಪತ್ತೈದನೆಯ ಅಧ್ಯಾಯ - ಮದೋನ್ಮತ್ತ ಇಬ್ಬರು ವಿಪ್ರರ ವೃತ್ತಾಂತ
  26. ಇಪ್ಪತ್ತಾರನೆಯ ಅಧ್ಯಾಯ - ವೇದವಿಸ್ತಾರ
  27. ಇಪ್ಪತ್ತೇಳನೆಯ ಅಧ್ಯಾಯ - ಮದೋನ್ಮತ್ತ ಬ್ರಾಹ್ಮಣರಿಗೆ ಶಾಪಪ್ರದಾನ
  28. ಇಪ್ಪತ್ತೆಂಟನೆಯ ಅಧ್ಯಾಯ - ಕರ್ಮವಿಪಾಕ ಕಥನ
  29. ಇಪ್ಪತ್ತೊಂಭತ್ತನೆಯ ಅಧ್ಯಾಯ - ಭಸ್ಮಮಹಿಮೆ
  30. ಮೂವತ್ತನೆಯ ಅಧ್ಯಾಯ - ಮೃತದ್ವಿಜಭಾರ್ಯಾ ಶೋಕ
  31. ಮೂವತ್ತೊಂದನೆಯ ಅಧ್ಯಾಯ - ಪತಿವ್ರತಾಧರ್ಮನಿರೂಪಣೆ
  32. ಮೂವತ್ತೆರಡನೆಯ ಅಧ್ಯಾಯ - ವಿಧವಾ ಆಚಾರ..ಪ್ರೇತಸಂಜೀವನ
  33. ಮೂವತ್ಮೂರನೆಯ ಅಧ್ಯಾಯ - ರುದ್ರಾಕ್ಷಿ ಮಹಿಮೆ
  34. ಮೂವತ್ನಾಲ್ಕನೆಯ ಅಧ್ಯಾಯ - ರುದ್ರಾಧ್ಯಾಯದ ಮಹಿಮೆ
  35. ಮೂವತ್ತೈದನೆಯ ಅಧ್ಯಾಯ - ಕಚದೇವಯಾನಿಯ ಕಥೆ
  36. ಮೂವತ್ತಾರನೆಯ ಅಧ್ಯಾಯ - ಆಚಾರಧರ್ಮ
  37. ಮೂವತ್ತೇಳನೆಯ ಅಧ್ಯಾಯ - ಆಹ್ನಿಕಧರ್ಮನಿರೂಪಣೆ
  38. ಮೂವತ್ತೆಂಟನೆಯ ಅಧ್ಯಾಯ - ಭಾಸ್ಕರ ಬ್ರಾಹ್ಮಣನ ಭಿಕ್ಷೆ
  39. ಮೂವತ್ತೊಂಭತ್ತನೆಯ ಅಧ್ಯಾಯ - ಬಂಜೆಗೆ ಸಂತಾನಪ್ರಾಪ್ತಿ
  40. ನಲವತ್ತನೆಯ ಅಧ್ಯಾಯ - ನರಹರಿಯ ಕುಷ್ಟರೋಗ ಹರಣ
  41. ನಲವತ್ತೊಂದನೆಯ ಅಧ್ಯಾಯ - ಸಾಯಂದೇವನಿಗೆ ಗುರುಪರೀಕ್ಷೆ
  42. ನಲವತ್ತೆರಡನೆಯ ಅಧ್ಯಾಯ - ಗುರುಭಕ್ತಿ, ಕಾಶಿಯಾತ್ರಾ ನಿರೂಪಣೆ
  43. ನಲವತ್ಮೂರನೆಯ ಅಧ್ಯಾಯ - ಅನಂತವ್ರತದ ಮಹಿಮೆ
  44. ನಲವತ್ನಾಲ್ಕನೆಯ ಅಧ್ಯಾಯ - ಶ್ರೀಶೈಲ, ಶಿವರಾತ್ರಿ ವರ್ಣನೆ
  45. ನಲವತ್ತೈದನೆಯ ಅಧ್ಯಾಯ - ನಂದಿ ಬ್ರಾಹ್ಮಣನ ಕುಷ್ಟ ಪರಿಹಾರ
  46. ನಲವತ್ತಾರನೆಯ ಅಧ್ಯಾಯ - ಕಲ್ಲೇಶ್ವರನಾಗಿ ನರಹರಿಯ ಉದ್ಧಾರ
  47. ನಲವತ್ತೇಳನೆಯ ಅಧ್ಯಾಯ - ಏಕಕಾಲದಲ್ಲಿ ಅಷ್ಟವಿಧರೂಪಧಾರಣೆ
  48. ನಲವತ್ತೆಂಟನೆಯ ಅಧ್ಯಾಯ - ಶೂದ್ರನ ಗುರುಭಕ್ತಿ
  49. ನಲವತ್ತೊಂಭತ್ತನೆಯ ಅಧ್ಯಾಯ - ರತ್ನಾಯಿಯ ಉದ್ಧಾರ
  50. ಐವತ್ತನೆಯ ಅಧ್ಯಾಯ - ಯವನರಾಜನ ಹುಣ್ಣಿನ ವೃತ್ತಾಂತ
  51. ಐವತ್ತೊಂದನೆಯ, ಐವತ್ತೆರಡನೆಯ ಅಧ್ಯಾಯ - ಕದಳೀವನದಲ್ಲಿ ಗುಪ್ತರಾದ ಯತಿವರರು, ಶಿಷ್ಯರಿಗೆ ಪ್ರಸಾದಪುಷ್ಪ ಪ್ರಾಪ್ತಿ
  52. ಐವತ್ಮೂರನೆಯ ಅಧ್ಯಾಯ - ಗುರುಚರಿತ್ರೆಯ ಮಹಿಮೆ
